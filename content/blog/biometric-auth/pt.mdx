Adicionar login biométrico a uma demo leva uma tarde. Publicar para milhares de usuários — com armazenamento de tokens, fallbacks e peculiaridades de cada aparelho — é outra história.

O princípio central: biometria nunca substitui seu sistema de autenticação; ela desbloqueia uma credencial armazenada localmente. Mantemos um refresh token no keychain/keystore do aparelho, protegido pelo prompt biométrico, e tratamos cada caminho de falha — nova digital cadastrada, hardware indisponível, cancelamento — como um fluxo de primeira classe de volta ao login com senha.

O resultado foi um login instantâneo e uma queda mensurável em redefinições de senha. O artigo completo com detalhes de implementação vem em breve.
